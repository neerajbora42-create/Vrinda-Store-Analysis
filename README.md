# Vrinda Store Data Analysis Project 📊

## Overview
This project analyzes Vrinda Store’s sales and customer data using **Microsoft Excel**.  
The goal is to uncover actionable business insights and demonstrate data analytics skills for portfolio presentation.

## Tools & Techniques
- Excel Pivot Tables & Pivot Charts
- Power Query for data cleaning
- Conditional Formatting
- Dashboard creation

## Dataset
- Source: Vrinda Store sales records (Excel file)
- Fields include: Date, Product, Category, Customer demographics, Sales channel, Revenue, Profit
